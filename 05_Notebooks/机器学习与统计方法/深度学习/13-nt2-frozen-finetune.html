模型微调

Sep 07, 202611 min read

  • finetune
  • Pytorch
  • NT2

上一次我们已经做了全量微调，《站在巨人的肩膀上：预训练模型之全量微调》，但是在真实场景中，预训练模型可能很大，全量微调需要为每个参数存梯度 + Adam 优化器状态，搞起来显存/算力都不现实。

更现实的做法是1）把预训练模型给冻结了，我们只训练MLP小头；2）冻结预训练模型的骨干，只解冻最后的k层，那么训练就是这最后的k层 + MLP小头，这是一种折中的方法。

前面已经学习《反向传播》，对冻结微调就很好理解了，冻结的参数就不动了。实际操作就是冻结的参数设 requires_grad = False，而优化器只优化可训练的参数，也就是只包含 requires_grad = True 的参数。其它的基本是一样的，这里我们做1）冻结微调（小头）、2）部分冻结（解冻末2层）和3）全量微调，并进行比较。

数据

冻结模型

freeze_backbone() 是全量冻结，所有参数都设 requires_grad = False，这个预训练模型的骨干是 model.esm 也就是 transformer encoder，所有参数都设为不可训练。

而 unfreeze_last_layers() 是部分冻结，只解冻最后 k 层，做法就是全部冻结，再解冻最后的 k 层。

MLP 小头

这里定义一个MLP小头，而build_mlp_head()就是把小头给模型接上。这里唯一需要讲的是 forward里的 x[:, 0, :]，为什么是这样来切片？

模型输出的features是三维的，model.outputs.last_hidden_states 或 encoder 出来的是：

features.shape = (batch, seq_len, hidden)
                      ↑        ↑
                      |        +── 每个 token 的向量长度（NT v2 50M 这个模型是 512）
                      +── 序列里有多少个 token（比如 max_length=128）

例如 batch=16、seq_len=128、hidden=512 → (16, 128, 512)。每一个位置（token）都有自己的一个 512 维向量。而分类头（nn.Linear(hidden, 128)）只接受二维输入 (batch, hidden)——它没法直接吞下 3D 的张量。所以必须先降维。

那么我们的做法是：

features[:, 0, :]
           │  │  │
           │  │  └── hidden 维：全保留（逗号前后留空 = 整个维度都要）
           │  └───── seq 维：只取下标 0（即序列里第 1 个 token）
           └──────── batch 维：全保留

也就是第二个位置的 0，就是说只取序列的第1位置的token。所以结果从 (16, 128, 512) 变成 (16, 512)——每个样本用一个 512 维向量表示，完美等于 MLP 头需要的 (batch, hidden)。

那么为什么要取第 0 个位置？这里的关键就是 核苷酸 Transformer（NT v2）和 ESM、BERT 一样，会在序列开头加一个特殊的 <cls>（也叫 CLS / BOS）token。它的特征是专门用来代表”整条序列的摘要”的——模型把整条序列的信息”汇聚”到这个 token 上，就像一句总结。所以每个样本取它那条 <cls> 向量，当作是这条序列的表示，这是标准做法。

当然我们也可以自己做这样的“一句话总结”，比如用x.mean(dim=1)就是对整体序列做average pooling。

优化器

全量微调用 model.parameters()，冻结模型下，只针对 requires_grad = True 的参数。

训练和评估

运行模型函数

基本上就是之前写的 main 了，这里改成 run 函数。差别就在于搞个三档的模式，以及为了比较，记录了可训练参数的比例和显存使用量等信息。

然后这里三档的学习率是不一样的。核心点在于如果调预训练的参数，学习率一大，就会冲掉预训练的权重，所以必须调小 lr。只训小头，lr 可以大一些，因为没有这个风险。部分解冻 lr 就得保守一些了。而全量微调，lr 必须要小。

综合这些结果我们可以观察到：

  • 冻结版显存最低、最快，但是 acc 上不去。因为表示没有适配到下游判别任务，另一个原因是CLS 单点读法太弱，所以换成 average pooling 之后上升了。
  • 解冻最后 2 层： acc 接近乃至反超全量，而显存只要约 1/3。
  • 全量微调，显存全开，acc 不见得比部分解冻好多少。
