全网吹的 Omarchy，无非是 Arch 加 DHH 的配置

全网吹的 Omarchy，无非是 Arch 加 DHH 的配置

Aug 30, 20267 min read

[!一句话版本：Omarchy 拆开就是普通 Arch + DHH 的配置。所谓”AI 系统”，不过是把状态栏里监控 CPU/内存的插件换成监控 token 用量；平铺窗口管理器？我玩 i3 的时候，这套东西全是自己配的。]

最近 Omarchy 挺火。

打开推送一看，全是”最美 AI Linux 发行版""为 AI 时代而生”。DHH 亲自站台，说要”truly democratize Linux”，还说 Linux 在开发者里要爆发了。

我就好奇，点进去看了一圈。

看完只有一个感想：这不就是 Arch Linux 加 DHH 的配置吗？

一、Omakase 是什么意思？就是替你选完

Omarchy 这名字，是 Omakase（お任せ，日料里的”厨师发办”）加 Arch。

意思很直白：厨师替你选好了，你负责吃。

做法也不复杂：把 Arch 装好，把 Hyprland 这个平铺窗口管理器配好、美化好，顺手塞一堆 AI 工具的启动器。4.0 版本连状态栏、启动器、通知中心，全写进一个叫 Quickshell 的东西里。

听着高大上？配方还是那个配方：

Arch + 窗口管理器 + 一套 dotfiles + 一堆快捷键。

区别只是，这套 dotfiles 是 DHH 写的。别人写的你不一定服气，DHH 写的，你就觉得是”思想”。

二、平铺窗口管理器，我多年前就在用

Omarchy 被吹得最响的，除了 AI，就是 Hyprland 平铺式窗口管理器，键盘驱动、不用鼠标。

这个我熟。

平铺窗口管理器这事，我十几年前就在用，那时候用的是 i3。在《你们想要的：QQ跑在Linux上》和《arch之打第一个AUR包》里，都晒过当时的桌面截图。

平铺窗口管理器有个特点：好看的东西，配出来得花时间。 状态栏、快捷键、主题，网上有现成的脚本和配置可以抄，但没有任何一样是开箱即用。

我那时候状态栏里那些 CPU、内存、网速的监控信息，网上抄了不少，自己也写了不少。i3bar、conky，改来改去，调颜色、对齐格式，折腾得不亦乐乎。

那时候管这个叫”折腾”，现在管这个叫”为 AI 时代而生”。

三、所谓 AI 系统，就是把监控对象换了一下

Omarchy 4.0 最核心的卖点是 AI 集成：预置一堆 AI coding agent（Claude、Codex、OpenCode……），选个默认 agent，快捷键一键拉起。

还有个顶栏的 agents 用量面板，显示订阅套餐用了多少百分比、每周额度剩多少、按天按模型的 token 用量。

这不就是当年我状态栏里监控 CPU、内存、网速的那套吗？ 数据源从 top、网卡计数器换成 API 账单和 token 计数，展示逻辑一毛一样。

所谓”AI 时代的系统”，就是把系统监控换成了 AI 监控。

换个监控对象，就成”为 AI 而生”了。这宣传，跟把 sysstat 改个名就敢叫”AI 运维平台”有一拼。

四、MacBook 装 Arch？我十年前也干过

还有人吹 Omarchy 让”老 Mac 用户逃离 macOS”（主要是Intel这波，已经食之无味了）。

这事我也干过。2019 年我就写过《MacBook安装Arch的一些设置》，在苹果笔记本上装 Arch，声音、网络、输入法、散热、风扇、电源，一样一样调。

用 Arch 给老苹果续命这事，那篇文章里说得很清楚：

买苹果的笔记本，不一定要用苹果的系统，相比于软件来说，更喜欢苹果的硬件。

再往前，PowerPC 时代我就折腾过 Gentoo、NetBSD。苹果从 PowerPC 到 Intel，我一路装过来。其实当年在PowerPC上折腾Linux和BSD，那真的叫让Mac重获新生。

所以看到”Omarchy 帮老 Mac 重获新生”这类标题，我就想：这剧情我熟啊，不过是把主角从 Arch+i3 换成了 Arch+Hyprland。

五、DHH 牛在哪？牛在影响力，不是技术

我不是说 Omarchy 不好。

平心而论，它做得挺用心。把 Arch 装好配好，对不想折腾的人来说确实是刚需。DHH 这种咖位的人亲自下场做 Linux 发行版，本身就是传播事件。他说的 “opinionated”，就是有态度、替你选好，这是他的强项。

但得认清一个事实：

Omarchy 没有发明任何新东西。 基于 Arch，包管理器是 pacman，窗口管理器是 Hyprland，配置是他自己的。任何一个玩过 Arch 的人，都能把这一套搭出来。

DHH 牛的地方，是把”别人配好的 Arch”做成了一个品牌，把”Linux 要爆发”送上了热搜。这背后是 Rails 创始人、37signals CTO 的光环，不是 Arch 突然变容易了。

这有何难？反正我当年是全都自己干的。

六、所以呢

想用 Omarchy？装个 ISO，一条命令的事，so easy。

想看懂 Omarchy？装个 Arch，再配一遍 Hyprland，就知道它替你省了多少活，也替你把多少”选择”藏起来了。

别把”别人配好的 Arch”当成新物种。 追热点可以，但至少得知道，热点底下垫着的，是你十几年前就玩剩下的那套东西。

人生苦短，我用 Arch。这个结论二十年前就有人说过了，换个皮肤也不会变。
